# FR-010: Barcode Lookup

## Requirement

**ID:** FR-010
**Title:** Barcode Lookup
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall allow the user to identify a food by scanning its barcode with the device camera and looking the product up on Open Food Facts.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-007 | Obtain nutrition data by scanning a product barcode |
| Customer Problem | CP-005 | The user expects to log packaged foods quickly and accurately |

## Acceptance Criteria

- [ ] A scanned barcode triggers an Open Food Facts lookup for that product.
- [ ] A found product can be logged or saved to the local catalog.
- [ ] A barcode not found on Open Food Facts offers the user a path to create a custom food or contribute the product.
- [ ] Camera permission denial is handled with a clear message.
