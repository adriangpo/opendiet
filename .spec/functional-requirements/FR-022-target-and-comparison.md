# FR-022: Daily Target and Comparison

## Requirement

**ID:** FR-022
**Title:** Daily Target and Comparison
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall allow the user to set a daily nutrient target and shall display each day's totals against that target.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-015 | Know accurate daily totals compared against a target the user sets |
| Customer Problem | CP-010 | The user must be able to trust the numbers and act on them |

## Acceptance Criteria

- [ ] The user can set and edit a daily target for at least energy and macros.
- [ ] The diary shows current totals against the target (e.g. remaining/over).
- [ ] With no target set, totals are still shown without error.
- [ ] No automatic goal calculation (BMR/TDEE) is implied; the target is user-entered (calculators are v2).
