# FR-017: Log Recipe by Servings

## Requirement

**ID:** FR-017
**Title:** Log Recipe by Servings
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall allow the user to log a recipe to the diary by specifying the number of servings consumed.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-011 | Log a recipe by the number of servings consumed |
| Customer Problem | CP-007 | The user who cooks expects accurate logging of home recipes |

## Acceptance Criteria

- [ ] A recipe can be added to a diary meal slot with a servings amount (including fractional servings).
- [ ] The logged entry's nutrition equals per-serving nutrition multiplied by the servings consumed.
- [ ] The entry contributes to the day's totals like any other diary entry.
