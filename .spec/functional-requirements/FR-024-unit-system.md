# FR-024: Unit System

## Requirement

**ID:** FR-024
**Title:** Unit System
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall let the user select a metric or imperial unit system and shall accept input and display amounts and totals in the selected system while storing canonical metric values.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-017 | Accept and display amounts in the user's chosen unit system |
| Customer Problem | CP-011 | The user expects familiar units to avoid errors |

## Acceptance Criteria

- [ ] The user can choose between metric and imperial in settings.
- [ ] Amounts entered in the chosen system are stored as canonical metric.
- [ ] Amounts and totals are displayed in the chosen system, with conversions consistent in both directions.
- [ ] Changing the unit system does not alter stored values, only their presentation.
