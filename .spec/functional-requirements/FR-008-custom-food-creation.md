# FR-008: Custom Food Creation

## Requirement

**ID:** FR-008
**Title:** Custom Food Creation
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall allow the user to create and edit a custom food with a name, a serving definition, and full nutrition-label plus micronutrient values.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-006 | Create custom foods with full label and micronutrient values |
| Customer Problem | CP-005 | The user expects to log the foods they actually eat |

## Acceptance Criteria

- [ ] A custom food can be created with name, serving size/unit, and per-100 g/ml or per-serving basis.
- [ ] Energy, full label macros (incl. sugars, saturates, fiber, salt/sodium), and micronutrient fields can be entered; unknown fields may be left blank.
- [ ] A custom food can be edited after creation and is immediately available for logging.
