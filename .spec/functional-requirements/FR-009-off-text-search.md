# FR-009: Open Food Facts Text Search

## Requirement

**ID:** FR-009
**Title:** Open Food Facts Text Search
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall allow the user to search Open Food Facts for foods by text query.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-007 | Obtain nutrition data by searching Open Food Facts |
| Customer Problem | CP-005 | The user expects to find the packaged foods they eat |

## Acceptance Criteria

- [ ] A text query returns matching Open Food Facts products with their nutrition data.
- [ ] Results indicate when a product is missing nutrition fields.
- [ ] A search with no results, or made while offline, surfaces a clear, non-blocking message.
