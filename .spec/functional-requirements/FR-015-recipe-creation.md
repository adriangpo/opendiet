# FR-015: Recipe Creation

## Requirement

**ID:** FR-015
**Title:** Recipe Creation
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall allow the user to create a recipe composed of foods with quantities and a defined yield (number of servings).

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-010 | Create recipes from foods with a yield |
| Customer Problem | CP-007 | The user who cooks expects accurate home-recipe nutrition |

## Acceptance Criteria

- [ ] A recipe can include one or more ingredients, each a food with a quantity.
- [ ] A recipe defines a yield expressed as a number of servings.
- [ ] A recipe can be edited (ingredients, quantities, yield) after creation.
