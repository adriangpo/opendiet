# FR-004: Daily Nutrient Totals

## Requirement

**ID:** FR-004
**Title:** Daily Nutrient Totals
**Priority:** Must Have
**Status:** Draft

### Statement

OpenDiet shall compute and display per-day nutrient totals from local data, without requiring a network connection.

## Traceability

| Traces To | ID | Description |
|-----------|-----|-------------|
| Customer Need | CN-002 | Show daily totals using on-device data |
| Customer Need | CN-015 | Know accurate daily nutrient totals |
| Customer Problem | CP-010 | The user must be able to trust the numbers |

## Acceptance Criteria

- [ ] Totals reflect all of a day's diary entries across every meal slot.
- [ ] Totals include energy, full label macros, and tracked micronutrients.
- [ ] Totals update immediately when an entry is added, edited, or removed.
- [ ] Totals are computed entirely offline.
